# Contributing

Thanks for considering a contribution!

1. Open an issue to describe a bug or proposed change before starting large work.
2. Create a focused branch for your change.
3. Keep changes small and explain why they are needed.
4. Run the test suite with `python -m pytest`.
5. Update the README when controls, setup, or behavior changes.
6. Open a pull request with a clear summary and testing notes.

Please be respectful and constructive in issues and reviews.
